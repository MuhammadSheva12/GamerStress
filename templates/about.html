Tentang
Penelitian Ini

Program Studi Teknik Informatika — mempelajari hubungan antara pola kebiasaan bermain Mobile Legends dan tingkat stres pemain menggunakan pendekatan machine learning.

🎯

Tujuan Penelitian

Memprediksi tingkat stres pemain Mobile Legends berdasarkan pola kebiasaan bermain menggunakan algoritma Random Forest.

📋

Instrumen PSS-10

Perceived Stress Scale (PSS-10) adalah instrumen tervalidasi secara ilmiah untuk mengukur tingkat stres melalui 10 pertanyaan berskala 0–4. Instrumen ini digunakan pada tahap pengumpulan data untuk melatih model — pengguna sistem tidak perlu mengisinya lagi saat melakukan prediksi.

🌲

Algoritma Random Forest

Metode ensemble learning yang menggabungkan banyak decision tree untuk menghasilkan prediksi yang lebih akurat dan stabil dibanding model tunggal.

📊

Data & Variabel

12 variabel digunakan sebagai input model, mencakup usia, jenis kelamin, status utama, durasi sesi, frekuensi bermain per hari, waktu bermain, win rate, kekalahan beruntun, orientasi bermain, mode game, cara bermain, dan rank.
